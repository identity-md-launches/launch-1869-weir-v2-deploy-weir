# Weir website: import and validation record

Job: publish the redesigned Weir. website to the site label `weir`, replacing the version served there, working against Weir v2 (launch 1869, contract `0xde049547f1e55bb093e14d8f4545d1cc9b613f97` on Robinhood Chain 4663). The site was already built and approved by the owner; this job imported it and checked it. It did not redesign, restyle, rewrite copy, rename or add anything. This is the worker's own record, not an independent certification. Publication, pinning and the ENS name are the platform's steps after this job.

## Scope and assumptions

- Source: `https://github.com/SwarmStream/weir` at commit `bf5fa02392c5c0fd1f7bb4b29ade63396025414b`, fetched with a depth-1 fetch of that exact commit. Its `web/` (Vite + React + wagmi source, lockfile, tests) and `dist/` (the finished static export) were extracted with `git archive` into this repository. All 118 blobs are byte-identical to the upstream tree (`git hash-object` compared against `git ls-tree`).
- `dist/` is published exactly as committed upstream: no rebuild, no recompression, no renamed file. `dist/imd-deployment.json` and `dist/abi/` are untouched.
- The deployment file names two contracts on chain 4663: the WEIR token `0x58b82fa656ecf47a0dca5be6bad06b92e22f7dbe` from the earlier launch 1780, and Weir v2 `0xde049547f1e55bb093e14d8f4545d1cc9b613f97` from this project's launch 1869 (source commit `108660578606392f284fe2ad19bd8b576ece0bae`, attestation `87f6b46bf48f07b1406efa6bcd83c8c18794c031c5797841a282bbdf60543582`). Whether the platform accepts a site whose deployment file names a contract from another launch is the platform's decision; nothing else was published or changed to work around it.
- Build tooling was never run inside `web/`. A copy under `test/scratch/webbuild/` received `npm ci` and produced a scratch `dist/` that was compared with the committed one. No `node_modules`, caches or vendored registry are in the submission.
- The design review covers the five hash routes (`#/`, `#/create`, `#/streams`, `#/records`, `#/stream/<id>`) and the wallet, create, stream, dispute, records and receipt flows. Findings against the approved design are recorded, not applied, because the brief forbids changes to the site.
